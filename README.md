# 💰 Personal Finance & Expense Analysis Dashboard

## 📌 Project Overview

The **Personal Finance & Expense Analysis Dashboard** is an Excel-based data analytics project designed to analyze personal income, expenses, savings, and spending patterns.

The project transforms raw financial transaction data into meaningful insights using **Excel formulas, Pivot Tables, KPIs, and interactive visualizations**. The dashboard provides a clear overview of financial performance and helps identify major spending categories and expense trends.

---

## 🎯 Objectives

* Track income and expenses efficiently
* Analyze spending patterns
* Identify major expense categories
* Calculate savings and financial balance
* Create meaningful financial KPIs
* Present insights through an interactive dashboard

---

## 🗂️ Project Structure

The Excel workbook contains the following sections:

### 1. Raw Data

Contains the original transaction-level financial data, including income and expense records.

**Includes:**

* Transaction Date
* Category
* Description
* Transaction Type
* Amount

### 2. Summary

Provides an aggregated analysis of the financial data.

**Key metrics include:**

* Total Income
* Total Expenses
* Total Savings
* Category-wise Expenses
* Financial Summary

### 3. Dashboard

An interactive visual dashboard that presents important financial insights through:

* 📊 KPI Cards
* 📈 Expense Trends
* 💰 Income vs. Expense Analysis
* 🏷️ Category-wise Expense Analysis
* 📉 Financial Performance Overview
